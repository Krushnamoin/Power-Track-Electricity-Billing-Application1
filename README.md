# ⚡ PowerTrack Electricity Billing System

## 📌 Project Description
Power Track Electricity Billing System is a web-based application designed to manage electricity billing efficiently. It allows users to calculate electricity bills, manage customer records, and track usage history.

---

## 🚀 Features
- ➕ Add new customers  
- ✏️ Update customer details  
- 🧮 Calculate electricity bills  
- 📊 View billing history  
- 🧾 Generate bill reports  
- 🔐 Admin dashboard  

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Tools:** Git, GitHub  

---

## 📂 Project Structure
client/ # React frontend
server/ # Node backend
models/ # Database schemas
routes/ # API routes
